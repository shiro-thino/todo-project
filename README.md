# TODO管理プログラム

## 機能

- 未完了TODOの表示
- 完了したTODOの表示
- 優先度の表示

## 起動方法

python todo.py

## 現在の表示

- 未完了と完了済みを一つの一覧に表示
- 完了済みTODOには[完了]を表示

## 実行環境

- Python 3を使用します。授業で動作確認済みのPython環境で実行してください。
- この版は追加のPythonパッケージを必要としません。
- コマンドプロンプトで、todo.pyがあるフォルダからpython todo.pyを実行します。

## 件数と優先度

- 一覧の件数は、未完了と完了済みを合わせた件数です。
- 各TODOの末尾に優先度を表示します。この版のデータは「高」「中」「低」です。
- 表示は登録順です。優先度による並べ替えは行いません。

## この版でできること・できないこと

- 起動時に初期データ2件へ「発表資料を作る」を追加し、毎回同じ3件を表示します。
- 入力画面や、実行中に利用者がTODOを追加する操作はありません。
- ファイルやデータベースへの保存機能はありません。繰り返し実行しても件数は増えません。
